ملفات إعداد Railway لمنصة GLH

الموجود في المستودع حالياً:
GLH_Render_Deploy_Package_0.1.1-1.zip

المطلوب إضافة الملفين التاليين إلى جذر مستودع GitHub (نفس مستوى ملف ZIP):
1) Dockerfile
2) railway.json

لا ترفع المجلد الحاوي لهذه الملفات كما هو، بل ارفع الملفين إلى جذر المستودع.
لا تحذف الملفات الموجودة.

بعد إضافتهما:
1. افتح Railway وافتح مشروعك المرتبط بمستودع GitHub.
2. أضف خدمة قاعدة بيانات PostgreSQL (New -> Database -> PostgreSQL).
3. أضف متغيرات البيئة لخدمة التطبيق:
   DATABASE_URL = مرجع متغير قاعدة البيانات من خدمة PostgreSQL، عادةً ${{Postgres.DATABASE_URL}}
   JWT_SECRET = قيمة عشوائية طويلة وفريدة لا تقل عن 32 حرفاً.
   SEED_ADMIN_PASSWORD = كلمة مرور تختارها أنت، 12 حرفاً على الأقل. لا تضعها في GitHub ولا ترسلها في المحادثة.
   SEED_DEMO_DATA = false (أو true لإضافة بيانات عرض تجريبية).
4. في إعدادات خدمة التطبيق، تأكد أن Root Directory فارغ (جذر المستودع) وأن Builder هو Dockerfile.
5. أعد Deploy وانتظر نجاح البناء.
6. من Settings -> Networking -> Generate Domain أنشئ النطاق العام.
7. اختبر: https://اسم-النطاق/api/health
   يجب أن تظهر نتيجة JSON فيها status: ok.
8. افتح https://اسم-النطاق لواجهة GLH.

مهم: هذا تجهيز أولي للنشر والاختبار، وليس دليلاً على اكتمال جميع قطاعات المنصة أو جاهزيتها للإنتاج. لا يوجد تكامل حقيقي مع SWIFT أو بوابات دفع.
