# حزمة Android الأولية لـ GLH

تمت إضافة إعداد Capacitor وهوية التطبيق وإرشادات بناء Android إلى السورس الحالي. لا يوجد APK ضمن الحزمة لأن بيئة إعداد هذا الإصدار لا تحتوي على Android SDK/Gradle ولا يمكن إجراء بناء وتوقيع فعلي هنا.

اتبع `ANDROID_BUILD_AR.md` بعد تثبيت Android Studio. لا تعتبر التطبيق جاهزاً للنشر قبل ضبط عنوان HTTPS الحقيقي، بناء APK، وتجربة الوظائف على هاتف فعلي.

لبناء APK تجريبي دون تثبيت Android Studio محلياً، اتبع `ANDROID_BUILD_CLOUD_AR.md` بعد رفع المشروع إلى GitHub.
