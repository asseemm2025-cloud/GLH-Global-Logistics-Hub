# منصة GLH — Global Logistics Hub

الإصدار: **0.6.15**

يوفر المشروع طريقتين لتشغيل المنصة نفسها:

- **محلياً للتجربة:** باستخدام Docker Compose لتشغيل خادم GLH وقاعدة PostgreSQL على الكمبيوتر، ثم فتح الواجهة من `http://localhost:4000`.
- **عبر الإنترنت:** باستخدام GitHub وRender وقاعدة PostgreSQL مستضافة، ثم فتح المنصة من رابط HTTPS.

ابدأ بقراءة `DUAL_RUN_MODES_AR.md`؛ فهو الدليل الأساسي للخطوات بالتفصيل. لا تفتح ملفات HTML مباشرة من مدير الملفات، لأن ذلك لا يشغّل الخادم ولا قاعدة البيانات.

## الاختبارات
من جذر المشروع: `npm test`.
وللتحقق من مخطط Prisma بعد تثبيت الحزم: `npm run db:validate`.
وللتحقق من اتصال قاعدة البيانات بعد التشغيل: افتح `/api/ready`.

## حالة الاعتماد
هذه نسخة تطوير وتجربة. راجع `IMPLEMENTATION_STATUS_AR.md` لمعرفة ما تم تنفيذه وما لم يتم اعتماده بعد. نجاح تشغيل الخادم أو نشره لا يعني أن جميع العمليات أو التكاملات الخارجية جاهزة للإنتاج.

## تطبيق Android

أضيف مسار بناء APK تجريبي عبر GitHub Actions. راجع `mobile/ANDROID_BUILD_CLOUD_AR.md`. هذا المسار يحتاج رفع المشروع إلى GitHub وتشغيل Workflow؛ لا يتضمن ZIP ملف APK جاهزاً.
